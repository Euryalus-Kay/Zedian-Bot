Setup Guide
1. Reddit API — Go to reddit.com/prefs/apps, create a "script" app, add your client ID and secret to the .env file.
2. Claude AI — Get an API key from console.anthropic.com and add it to .env.
3. YouTube — Create a project in Google Cloud Console, enable YouTube Data API v3, download client_secrets.json to project root.
4. Backgrounds — Go to the Backgrounds tab and download at least one gameplay video.
5. Tunnel (optional) — Set CLOUDFLARE_TUNNEL=true in .env for public access.
Environment File

Copy .env.example to .env and fill in:

REDDIT_CLIENT_ID=your_client_id
REDDIT_CLIENT_SECRET=your_client_secret
ANTHROPIC_API_KEY=your_api_key
FLASK_SECRET_KEY=random-secret
CLOUDFLARE_TUNNEL=false
