Setup Guide — Step by Step
Step 1: Install Python 3.10+
Download from python.org/downloads. On Mac you can also use brew install python. Make sure to check "Add to PATH" during install on Windows.
Step 2: Install FFmpeg
Required for video editing. Download from ffmpeg.org.
Windows: Download, extract, add the bin folder to your system PATH.
Mac: brew install ffmpeg
Linux: sudo apt install ffmpeg
Step 3: Clone and install
Open a terminal and run: 
git clone https://github.com/Euryalus-Kay/Zedian-Bot.git
cd Zedian-Bot
pip install -r requirements.txt
Step 4: Get a Claude API key (required)
Go to console.anthropic.com, create an account, go to API Keys, create a new key. Copy it.
Step 5: Create your .env file
In the project folder, copy .env.example to .env and paste your key: 
# Copy .env.example to .env, then edit:
cp .env.example .env

# Required - paste your Claude key:
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx

# Optional - only needed if you want Reddit scraping:
REDDIT_CLIENT_ID=your_id
REDDIT_CLIENT_SECRET=your_secret
REDDIT_USER_AGENT=ViralStoryBot/1.0

# Flask
FLASK_SECRET_KEY=any-random-string-here
FLASK_PORT=5000
Step 6: Set up YouTube upload (optional)
1. Go to Google Cloud Console
2. Create a new project (any name)
3. Go to APIs & Services → Library
4. Search "YouTube Data API v3" and click Enable
5. Go to APIs & Services → Credentials
6. Click Create Credentials → OAuth client ID
7. Application type: Desktop app
8. Download the JSON file and save it as client_secrets.json in the project root
9. Go to OAuth consent screen, add your Google email as a test user
10. In the app, go to the YouTube tab and click "Connect YouTube"
Step 7: Download a background video
Go to the Backgrounds tab in this app and download at least one gameplay video (Minecraft Parkour, Subway Surfers, etc.). This is used behind the captions.
Step 8: Run the app 
python app.py

# Then open http://localhost:5000 in your browser
Step 9: Go to Autopilot and hit Launch!
Pick a style, and the bot will write a story, narrate it, add captions and background, and optionally upload it to YouTube. Fully automatic.
What you need vs what's optional
Claude API key Required
FFmpeg Required
